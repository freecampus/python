# About this edition

This is the complete Python Foundations course from FreeCampus: one connected
sequence of 16 units, 97 lessons, and 16 unit challenges. It starts with no
programming experience and continues through practical Python projects, testing,
packaging, command-line applications, and documentation.

This PDF is generated from the same lesson files as the website. Curriculum
version **{{version}}** is printed here; the website may receive later
corrections. Use the online edition when you need the latest material.

The book is designed for focused reading, annotation, and printing. It includes
all lesson explanations and code, printable checkpoints, visible hints and
solutions, and a separate checkpoint answer key. Diagrams are adapted for the
page; labeled transitions are also written below them.

Code is printed as source, not executed by the PDF build. Expected output and
intentional error examples remain part of the lessons. A small continuation
arrow at the end of a long code line means the line wraps on paper; it is not
Python syntax. Do not type the arrow when copying code.

Every lesson begins with a link to its online page, where you can open its
matching Colab notebook. A PDF cannot run code, grade a quiz, or update browser
progress. The study record at the end is for your own notes and is not a grade,
verified completion record, or certificate. The final project and certificate
are planned, not included as available credentials.

FreeCampus makes rigorous learning materials open to everyone. You can study at
your own pace, share the course, and contribute corrections. The complete BSD
3-Clause license and source link appear at the end of the book.

Unit Challenge: Build a Date-Aware Purchase Summary

Repair a time-travel supply record by converting raw text, choosing numeric representations, checking facts, calculating an aware review date, and formatting a clearance message.
python-foundations core-values-types unit-challenge
↗ Open in Colab
Course progress 0%
  • Level: Python Foundations · Unit 2 challenge
  • Estimated time: 60–120 minutes
  • Outcome assessed: Choose, convert, compare, calculate, and format text, numeric, Boolean, missing, and timezone-aware values in one reproducible artifact.
  • Evidence: Progressive checks, a decoded clearance message, one boundary rerun, and one debugging record

Open this lesson in Google Colab

1. Challenge outcome

The Chrononaut Supply Kiosk has recovered a purchase record from a damaged time capsule. Every field survived as text, several values carry extra whitespace, and the cargo scanner stored the familiar floating-point result of 0.1 + 0.2.

Repair the record and unlock its clearance message. Your program must preserve the raw evidence, create values with deliberate types, calculate exact credit totals, confirm the measured cargo mass with a tolerance, retain the timestamp’s UTC offset, derive a small launch code, and produce one stable summary.

The challenge is a puzzle, but its rules are all on this page. You do not need collections, loops, functions, conditional statements, or exception handlers.

NoteMission rule

Run one assertion group at a time. When a group fails, read the first failure and repair the value that group describes. Do not edit expected values merely to open the next stage.

2. Understand the acceptance example

The repaired record must produce exactly this clearance message:

=== CHRONONAUT SUPPLY CLEARANCE ===
Traveler: Ada Byron [AS0803]
Cargo: 4 × Quantum Compass
Credits: 13.00 + 0.98 = 13.98
Mass check: PASS | Priority: True
Review: 2026-09-02 14:30 UTC

The launch code is not random:

  • A is the first character of the cleaned traveler name;
  • S is the final character of the cleaned item name; and
  • 0803 is the purchase month and day.

Before writing code, identify which displayed values should remain strings, which should become int, float, Decimal, bool, None, or datetime, and which values exist only for formatted output.

Constraints

  1. Preserve every supplied name ending in _text unchanged.
  2. Keep the supplied public names so the progressive assertions can inspect them.
  3. Construct Decimal values directly from text, not through float.
  4. Use ROUND_HALF_UP and quantize the service fee to Decimal("0.01").
  5. Parse priority by cleaning and comparing text; do not use bool(priority_text).
  6. Represent the blank coupon code with None and check it with is None.
  7. Use math.isclose() with the supplied absolute tolerance for the mass check.
  8. Parse the aware ISO timestamp rather than slicing its date characters.
  9. Derive the launch code from the cleaned values and parsed timestamp.
  10. Do not hard-code calculated totals, the review timestamp, code, status, or complete summary.

4. Build in small stages

Stage A: restore typed values

  1. Strip and title-case the traveler and item display values.
  2. Build traveler_key by stripping, NFC-normalizing, and casefolding the raw traveler text. This key is evidence that you can prepare text for matching without replacing the display name.
  3. Convert the quantity and review-day count to integers.
  4. Construct the price and service rate as Decimals from their source strings.
  5. Convert the measured mass to float.
  6. Parse priority with an explicit cleaned-text comparison.
  7. Clean the coupon text and use or None to represent its absence.
  8. Parse the ISO timestamp with datetime.fromisoformat().

Run assertion group A before continuing.

Stage B: recover the purchase and time facts

  1. Multiply unit price by quantity for the exact subtotal.

  2. Calculate the raw service fee, then quantize it to cents with ROUND_HALF_UP.

  3. Add subtotal and fee for the total.

  4. Compare the measured and expected masses using an absolute tolerance and no relative tolerance.

  5. Use the supplied expression below to turn the Boolean mass fact into display text without introducing a conditional statement:

    mass_status = ("FAIL", "PASS")[mass_matches]

  6. Add the converted review-day duration to the aware purchase timestamp.

  7. Derive the launch code from the two characters and strftime("%m%d").

  8. Combine the important Boolean facts into record_ready.

Run assertion group B before formatting the summary.

Stage C: assemble the clearance message

Use adjacent f-strings inside parentheses. Format every Decimal credit value with two decimal places and the review timestamp with %Y-%m-%d %H:%M UTC. Preserve the exact line breaks and labels shown in the acceptance example.

5. Run progressive assertions

Group A: cleaned and converted values

expected_summary = (

WarningA later pass does not erase an earlier failure

If group B fails because service_fee is 0.975, the Decimal conversion is not the problem. The missing step is the stated cent-quantization rule. Diagnose the first mismatched promise before changing other values.

9. Compare with a solution path

Reveal after all three hint levels have been used or your own checks pass 
import math
import unicodedata
from datetime import datetime, timedelta
from decimal import Decimal, ROUND_HALF_UP

traveler_text = "  aDA BYRON  "
item_text = "quantum compass"
quantity_text = "4"
unit_price_text = "3.25"
service_rate_text = "0.075"
mass_text = "0.30000000000000004"
priority_text = " YES "
coupon_text = "   "
purchased_at_text = "2026-08-03T14:30:00+00:00"
review_days_text = "30"

expected_mass = 0.3
mass_tolerance = 0.000001
cent = Decimal("0.01")

traveler = traveler_text.strip().title()
traveler_key = unicodedata.normalize("NFC", traveler_text.strip()).casefold()
item = item_text.strip().title()
quantity = int(quantity_text)
unit_price = Decimal(unit_price_text)
service_rate = Decimal(service_rate_text)
measured_mass = float(mass_text)
is_priority = priority_text.strip().casefold() == "yes"
coupon_code = coupon_text.strip() or None
purchased_at = datetime.fromisoformat(purchased_at_text)
review_days = int(review_days_text)

subtotal = unit_price * quantity
service_fee = (subtotal * service_rate).quantize(
    cent,
    rounding=ROUND_HALF_UP,
)
total = subtotal + service_fee
mass_matches = math.isclose(
    measured_mass,
    expected_mass,
    rel_tol=0.0,
    abs_tol=mass_tolerance,
)
mass_status = ("FAIL", "PASS")[mass_matches]
review_at = purchased_at + timedelta(days=review_days)
launch_code = (
    traveler[0].upper()
    + item[-1].upper()
    + purchased_at.strftime("%m%d")
)
record_ready = (
    quantity > 0
    and mass_matches
    and purchased_at.tzinfo is not None
    and coupon_code is None
)

summary = (
    "=== CHRONONAUT SUPPLY CLEARANCE ===\n"
    f"Traveler: {traveler} [{launch_code}]\n"
    f"Cargo: {quantity} × {item}\n"
    f"Credits: {subtotal:.2f} + {service_fee:.2f} = {total:.2f}\n"
    f"Mass check: {mass_status} | Priority: {is_priority}\n"
    f"Review: {review_at:%Y-%m-%d %H:%M UTC}"
)

print(summary)

This path keeps external text visible, performs calculations on typed values, and creates display text only at the end. A different implementation is valid when it preserves the names, constraints, and unchanged assertions.

10. Check your understanding

{
  const scripts = Array.from(
    document.querySelectorAll("script.fcpython-ojs-quiz-config")
  );
  const script = scripts.find(
    (node) => node.dataset.fcpythonRendered !== "true"
  );

  if (!script) {
    return html`<div class="fcpython-quiz fcpython-quiz-warning">
      Quiz configuration was not found.
    </div>`;
  }

  script.dataset.fcpythonRendered = "true";
  const quiz = JSON.parse(script.textContent);
  const container = html`<div class="fcpython-quiz"></div>`;
  const title = document.createElement("h3");
  title.textContent = quiz.title;
  container.appendChild(title);

  const instructions = document.createElement("p");
  instructions.textContent = quiz.instructions;
  container.appendChild(instructions);

  const progress = document.createElement("div");
  progress.className = "fcpython-quiz-progress";

  const counter = document.createElement("p");
  counter.className = "fcpython-quiz-counter";
  counter.setAttribute("aria-live", "polite");
  progress.appendChild(counter);

  const tabs = document.createElement("div");
  tabs.className = "fcpython-quiz-steps";
  tabs.setAttribute("role", "tablist");
  tabs.setAttribute("aria-label", "Quiz questions");
  progress.appendChild(tabs);
  container.appendChild(progress);

  const questions = document.createElement("div");
  questions.className = "fcpython-quiz-questions";

  const feedbackNodes = [];
  const questionPanels = [];
  const stepButtons = [];
  let currentQuestion = 0;

  function setStepStatus(questionIndex, status) {
    const step = stepButtons[questionIndex];
    const question = quiz.questions[questionIndex];
    const statuses = {
      answered: "answered",
      correct: "correct",
      incorrect: "incorrect",
      unanswered: "not answered",
    };

    step.classList.remove(
      "is-answered",
      "is-correct",
      "is-incorrect",
      "is-unanswered"
    );
    if (status) {
      step.classList.add(`is-${status}`);
    }

    const statusLabel = status ? `, ${statuses[status]}` : "";
    step.setAttribute(
      "aria-label",
      `Question ${questionIndex + 1}: ${question.prompt}${statusLabel}`
    );
  }

  function showQuestion(questionIndex, focusPanel = false) {
    currentQuestion = Math.max(
      0,
      Math.min(questionIndex, quiz.questions.length - 1)
    );

    questionPanels.forEach((panel, index) => {
      panel.hidden = index !== currentQuestion;
    });
    stepButtons.forEach((step, index) => {
      const isCurrent = index === currentQuestion;
      step.classList.toggle("is-current", isCurrent);
      step.setAttribute("aria-selected", String(isCurrent));
      step.tabIndex = isCurrent ? 0 : -1;
    });

    counter.textContent = `Question ${currentQuestion + 1} of ${quiz.questions.length}`;

    const selected = questionPanels[currentQuestion].querySelector(
      "input[type='radio']:checked"
    );
    const isLastQuestion = currentQuestion === quiz.questions.length - 1;
    previous.hidden = currentQuestion === 0;
    next.hidden = isLastQuestion || !selected;
    check.hidden = !isLastQuestion;

    if (focusPanel) {
      questionPanels[currentQuestion].focus();
    }
  }

  quiz.questions.forEach((question, questionIndex) => {
    const tabId = `${quiz.id}-question-tab-${questionIndex + 1}`;
    const panelId = `${quiz.id}-question-panel-${questionIndex + 1}`;

    const step = document.createElement("button");
    step.type = "button";
    step.className = "fcpython-quiz-step";
    step.id = tabId;
    step.textContent = String(questionIndex + 1);
    step.setAttribute("role", "tab");
    step.setAttribute("aria-controls", panelId);
    step.setAttribute("aria-selected", "false");
    step.tabIndex = -1;
    step.addEventListener("click", () => showQuestion(questionIndex));
    step.addEventListener("keydown", (event) => {
      let destination = null;
      if (event.key === "ArrowRight") {
        destination = (questionIndex + 1) % quiz.questions.length;
      } else if (event.key === "ArrowLeft") {
        destination =
          (questionIndex - 1 + quiz.questions.length) % quiz.questions.length;
      } else if (event.key === "Home") {
        destination = 0;
      } else if (event.key === "End") {
        destination = quiz.questions.length - 1;
      }

      if (destination !== null) {
        event.preventDefault();
        showQuestion(destination);
        stepButtons[destination].focus();
      }
    });
    stepButtons.push(step);
    tabs.appendChild(step);
    setStepStatus(questionIndex, "");

    const panel = document.createElement("div");
    panel.className = "fcpython-quiz-panel";
    panel.id = panelId;
    panel.setAttribute("role", "tabpanel");
    panel.setAttribute("aria-labelledby", tabId);
    panel.tabIndex = -1;

    const fieldset = document.createElement("fieldset");
    fieldset.className = "fcpython-quiz-question";

    const legend = document.createElement("legend");
    legend.textContent = question.prompt;
    fieldset.appendChild(legend);

    question.options.forEach((option, optionIndex) => {
      const label = document.createElement("label");
      label.className = "fcpython-quiz-option";

      const input = document.createElement("input");
      input.type = "radio";
      input.name = `${quiz.id}-${question.id}`;
      input.value = String(optionIndex);
      input.addEventListener("change", () => {
        setStepStatus(questionIndex, "answered");
        feedbackNodes[questionIndex].textContent = "";
        feedbackNodes[questionIndex].className = "fcpython-quiz-feedback";
        score.textContent = "";
        showQuestion(questionIndex);
      });

      const text = document.createElement("span");
      text.textContent = option;

      label.appendChild(input);
      label.appendChild(text);
      fieldset.appendChild(label);
    });

    const feedback = document.createElement("p");
    feedback.className = "fcpython-quiz-feedback";
    feedback.setAttribute("aria-live", "polite");
    feedbackNodes.push(feedback);
    fieldset.appendChild(feedback);
    panel.appendChild(fieldset);
    questionPanels.push(panel);
    questions.appendChild(panel);
  });

  container.appendChild(questions);

  const actions = document.createElement("div");
  actions.className = "fcpython-quiz-actions";

  const previous = document.createElement("button");
  previous.type = "button";
  previous.className = "fcpython-quiz-secondary";
  previous.textContent = "Previous";
  previous.addEventListener("click", () => {
    showQuestion(currentQuestion - 1, true);
  });

  const next = document.createElement("button");
  next.type = "button";
  next.textContent = "Next question";
  next.addEventListener("click", () => {
    showQuestion(currentQuestion + 1, true);
  });

  const check = document.createElement("button");
  check.type = "button";
  check.textContent = "Check answers";

  const reset = document.createElement("button");
  reset.type = "button";
  reset.className = "fcpython-quiz-secondary fcpython-quiz-reset";
  reset.textContent = "Reset";

  const score = document.createElement("p");
  score.className = "fcpython-quiz-score";
  score.setAttribute("aria-live", "polite");

  check.addEventListener("click", () => {
    let correctCount = 0;
    let firstQuestionToReview = null;

    quiz.questions.forEach((question, questionIndex) => {
      const selected = container.querySelector(
        `input[name="${quiz.id}-${question.id}"]:checked`
      );
      const feedback = feedbackNodes[questionIndex];

      if (!selected) {
        feedback.textContent = "Choose an answer before checking.";
        feedback.className = "fcpython-quiz-feedback";
        setStepStatus(questionIndex, "unanswered");
        if (firstQuestionToReview === null) {
          firstQuestionToReview = questionIndex;
        }
        return;
      }

      const selectedIndex = Number(selected.value);
      if (selectedIndex === question.answer_index) {
        correctCount += 1;
        feedback.textContent = `✅ Correct. ${question.explanation}`;
        feedback.className = "fcpython-quiz-feedback is-correct";
        setStepStatus(questionIndex, "correct");
      } else {
        const answer = question.options[question.answer_index];
        feedback.textContent = `❌ Not yet. Correct answer: ${answer}. ${question.explanation}`;
        feedback.className = "fcpython-quiz-feedback is-incorrect";
        setStepStatus(questionIndex, "incorrect");
        if (firstQuestionToReview === null) {
          firstQuestionToReview = questionIndex;
        }
      }
    });

    score.textContent = `Score: ${correctCount}/${quiz.questions.length}`;
    if (firstQuestionToReview !== null) {
      showQuestion(firstQuestionToReview, true);
    }
  });

  reset.addEventListener("click", () => {
    container.querySelectorAll("input[type='radio']").forEach((input) => {
      input.checked = false;
    });
    feedbackNodes.forEach((feedback) => {
      feedback.textContent = "";
      feedback.className = "fcpython-quiz-feedback";
    });
    stepButtons.forEach((_, questionIndex) => {
      setStepStatus(questionIndex, "");
    });
    score.textContent = "";
    showQuestion(0, true);
  });

  actions.appendChild(previous);
  actions.appendChild(next);
  actions.appendChild(check);
  actions.appendChild(reset);
  container.appendChild(actions);
  container.appendChild(score);
  showQuestion(0);
  return container;
}
